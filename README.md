# My Portfolio

A personal portfolio for Manish Chand, built to showcase full-stack projects, product thinking, and web development work in a clean, mobile-friendly experience.

Live Demo: https://chandmanish-web.github.io/My-Protfolio/

## Tech Stack
- HTML5 for semantic, accessible page structure
- CSS3 for modern styling, responsive layouts, and motion effects
- JavaScript for interactions, filtering, and UI behaviors
- Font Awesome for readable iconography

## Features
- Responsive single-page portfolio with clear sections for projects, skills, experience, and contact
- Interactive project filtering and polished motion effects
- Accessible navigation patterns, including a skip link and keyboard-friendly controls
- Contact form that opens a prefilled email draft for outreach

## Project Structure
This repository is intentionally flat and matches the current deployment layout:

## Local Preview
Open the project in a browser directly or run a simple local static server from the repository root:

```bash
python -m http.server 8000
```

Then visit: http://localhost:8000

## Notes
- The current live demo URL is the GitHub Pages URL above.
- The contact form is intended as a lightweight UI flow that opens the user's email client with a pre-filled message.
- The project files are kept in the root directory for simple GitHub Pages hosting and easy deployment.
